AI Study Helper

A personalized AI-powered study tool built to make learning less overwhelming.

About the Project

The AI Study Helper is a full-stack web application I built to serve as a personal, homemade tutor. My goal was to create an AI assistant that responds in a structured, digestible way — something I felt was missing from other AI tools where the responses can be overwhelming and hard to follow.

The app has two main modes: a General Knowledge Tutor for asking questions on any topic, and a Coding Tutor where you can paste any code and get a structured breakdown — what the code does, any bugs or issues, suggested improvements, and a direct answer to your specific question. A Flashcards feature is also planned for a future update.

Technologies Used

React Node.js Ollama LLaMA 3.1 SQLite JavaScript

Key Features

  • General Knowledge Tutor — ask the AI any question and get a clear, structured response
  • Coding Tutor — paste any code and ask a question; the AI returns what the code does, bugs found, improvements, and your specific answer
  • Responses formatted to avoid information overload — designed around how I personally learn best
  • Runs locally using Ollama + LLaMA 3.1, keeping all data private on your own machine
  • SQLite database for storing previous sessions and questions
  • Flashcards feature in development for reviewing past questions

Sample Code

Server-side API endpoint handling the AI response from Ollama:

// server/index.js — Ollama API call
app.post('/api/analyze', async (req, res) => {
  const { code, question } = req.body;

  const prompt = `
    You are a coding tutor. Analyze the following code and answer the question.
    Code: ${code}
    Question: ${question}
    Respond with:
    1. What the code does
    2. Any bugs or issues
    3. Suggested improvements
    4. Answer to the question
  `;

  const response = await fetch('http://localhost:11434/api/generate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      model: 'llama3.1',
      prompt: prompt,
      stream: false
    })
  });

  const data = await response.json();
  res.json({ response: data.response });
});
